## 独立IP到底解决了什么问题

共享IP或NAT模式的意思是：你和同机房的其他用户共用同一个公网IP，靠端口映射把自己的服务暴露出去。用起来没什么问题，直到出现下面这几种情况。

**端口不够用。** NAT机型通常只给你开放固定数量的端口（雨云一般是10个左右），做网站、跑API、开游戏服、跑邮件服务，端口很快就排到不够。独立IP没有这个限制，全部端口归你用。

**邻居出事，你跟着遭殃。** 共享IP上有人发垃圾邮件、跑违规业务、被DDoS，整个IP段被拉黑或流量清洗，你的服务跟着断。独立IP至少把风险隔离在你自己这一台机器上。

**建站需要IP直连。** 部分业务（SEO工具、爬虫、支付回调白名单、某些CDN对接）要求固定且独享的出口IP，共享IP反复变化会直接导致业务失败。

**防御要独享。** 这是国内机房贵的原因。宿迁的独立IP带150Gbps独享防御，十堰带100G独享高防，一台机器被打不会牵连别人，别人被打你也不受影响。

## 哪些情况其实不需要独立IP

这是被忽略最多的一部分。独立IP值得买，但前提是你的业务真的需要。

- **只是学习Linux、跑跑内网穿透、测试环境**：NAT机型完全够用，宿迁的NAT甚至免费给到共享150G防御。省下来的钱够你多租几个月。
- **个人小博客、访问量很低**：香港或美国机房5元/月的独立IP已经足够，但如果你连固定IP都不需要，这笔钱也可以先省下。
- **不开公网服务，只做自用代理或脚本**：独立IP的价值主要在于固定和独享，如果你不在意这些，共享IP不会影响使用。

反过来，下面这几种情况建议直接上独立IP：备案域名上国内机房、需要全端口、跑邮件服务器、做API服务需要IP白名单、网站被打过、需要给客户交付固定出口IP。

## 常见问题

**独立IP可以随时取消吗？**
不能。官方文档明确写了开通后不支持关闭，续费主机时需要继续支付IP费用，退订主机也不退IP费用。这也是为什么建议先确定业务再开IP，别抱着“先开着试试”的心态。

**买了独立IP还会因为别人被攻击而受影响吗？**
如果这个IP本身不带防御，而你的服务器挂在共享的清洗策略下，极端情况下仍可能受影响。真正想彻底隔离，选带独享高防的独立IP（宿迁150G、十堰100G这类）。

**香港/美国5元的独立IP够用吗？**
够建站、够跑服务端口，但它没有任何防御。被打的时候，要么临时上CDN，要么换到带高防的机房。日常业务用它是性价比最高的选择。

**国内机房一定要独立IP吗？**
湖北十堰是强制的，不买独立IP无法开通。宿迁可以不买，但NAT模式下不能用80、443端口对外提供网站服务（域名还需备案），基本只能做学习和内网穿透。

**独立IP能加几个？**
同一台云服务器最多可加购3个独立IP，加购数量按剩余天数计费。

## 说回选择本身

把前面的信息压缩成一句话：**独立IP的价格差异主要买的是防御和线路，不是IP本身。**
